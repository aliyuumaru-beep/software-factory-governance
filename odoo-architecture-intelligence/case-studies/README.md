# OAIS — Project Case Studies

**Status:** REGISTERED — no case studies yet
**Decision:** DEC-013

This directory records project-specific lessons and observations that are worth sharing across the Software Factory. These are distilled learnings, not project documentation.

## What belongs here

- Unexpected Odoo behaviour encountered in a project (and how it was resolved)
- OCA module assessment outcomes (positive and negative)
- Performance issues encountered and their root cause
- Security findings from project work
- Architecture decisions that turned out better or worse than expected

## What does NOT belong here

- Client credentials or API keys
- Database names, server IPs, or access URLs
- Personal data or client-identifiable information
- Project-specific configuration that is not a generalizable lesson

See `LESSONS_TEMPLATE.md` for the standard format.
