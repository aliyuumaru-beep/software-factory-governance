# OAIS — Architecture Laboratory

**Status:** PLACEHOLDER — no laboratory environment deployed
**Decision:** DEC-013

The Architecture Laboratory is a future capability for running practical experiments, reproducible tests, and competency assessments against an isolated Odoo environment.

## Purpose

- Reproduce reported Odoo behaviour to verify claims in `intelligence/`
- Test architecture patterns in isolation before recommending them
- Validate OCA module behaviour in a controlled environment
- Run competency assessments for new agents or developers

## Current status

No laboratory environment has been deployed. This is a placeholder for Phase 3 or later.

## Future scope (not in Phase 2)

- Isolated Odoo 17 Community Docker environment
- Experiment scripts that can be reproduced by any agent
- Results stored as `verified-findings/lab-verified/` entries
- Experiment template: `EXPERIMENT_TEMPLATE.md`

## When this becomes active

A Phase 3 work item will be required to deploy the laboratory environment and define the experiment protocol.
