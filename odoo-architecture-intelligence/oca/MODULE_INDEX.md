# OCA Module Index

**Status:** REGISTERED — schema defined; modules to be listed during Phase 2/3
**Decision:** DEC-013

This index lists all OCA modules identified as potentially relevant to Software Factory projects. Identification does not imply suitability. See individual assessment files for suitability determination.

---

## Schema

| Field | Description |
|-------|-------------|
| `Module` | Technical module name |
| `Repository` | OCA GitHub repository |
| `v17 Branch` | Confirmed `17.0` branch exists (Yes / No / Unknown) |
| `Domain` | Functional domain |
| `Purpose` | One-line purpose |
| `Assessment file` | Path to assessment in `oca/v17/{domain}/` |
| `Status` | REGISTERED / RETRIEVED / SOURCE_VERIFIED / SUITABLE / NOT_SUITABLE |
