# Source-Code References — Odoo 17 Enterprise

**Status:** NOT APPLICABLE — Enterprise source not publicly accessible
**Decision:** DEC-013

The Odoo Enterprise source repository requires an active licence to access and is not publicly available.

Any reference to Enterprise behaviour must be labelled: `[ENTERPRISE — source not independently verifiable]`

The Software Factory platform profile restricts all current projects to Community features only. Do not create source-code references for Enterprise-only features.
