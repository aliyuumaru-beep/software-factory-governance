# SOFTWARE_FACTORY_AGENT_FRAMEWORK.md

Defines the autonomous operating model for Software Factory projects: Level 1 Orchestrator, Level 2 shared governance agents, and Level 3 project delivery pods.

Core principle: maximize project progress within governance boundaries.

Project pods include D1 Functional Architect, D2 Solution Builder, D3 Quality & Validation, and D4 Knowledge & Documentation.

Governance agents are shared across pods: G1 Architecture & Odoo, G2 Quality & Documentation, G3 Security & Change.
