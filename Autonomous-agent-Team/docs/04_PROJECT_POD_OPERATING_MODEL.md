# PROJECT_POD_OPERATING_MODEL.md

Each client implementation operates as an independent Project Pod.

Mandatory pod artifacts: PROJECT_STATE.md, MILESTONE_TRACKER.md, BACKLOG.md, RISK_REGISTER.md, DECISION_LOG.md, CHANGELOG.md, IMPLEMENTATION_HISTORY.md, MODULE_REGISTRY.md, docs/governance/GOVERNANCE_APPROVAL_REGISTER.md (AOP-015 — executive view of all decisions grouped by department; updated at every Work Package exit gate).

Execution cycle: read state, identify work package, execute, governance review, close work package, update state, advance milestone, continue automatically.
